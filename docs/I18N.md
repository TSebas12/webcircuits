# i18n (M11-10..13)

Catálogo actual: `src/app/i18n/index.ts`.

Locales implementados (con fallback al español cuando falta una clave):
- `es` (base), `en`, `fr`, `de`, `pt`, `it`, `ja`, `zh`.

API:
- `t(key)` → traducción actual o la clave.
- `setLocale(locale)` → cambia idioma si existe.
- `availableLocales()` → lista.
- Detección automática por `navigator.language`.

Cualquier idioma no soportado cae a `es`.

Pendiente para M11-13: ampliar a 20+ idiomas (hu, tr, ko, ru, …) traduciendo todas las claves.
